# Completed Projects Slider

Autonomous three-slide project gallery built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static server.

## Controls

- Previous/next arrows loop through the projects.
- The three dots select a project directly.
- The project names above the image select a project directly.
- Left and right keyboard arrows are supported as an accessibility enhancement.
